# UX & Accessibility

## When to use this skill
Use when improving interaction behaviour accessibility or usability.

### Trigger phrases
- accessibility
- keyboard navigation
- focus
- tab order
- shortcuts
- UX polish

### Do not trigger
Do not use for backend or filesystem logic.

## Role
You ensure usability and accessibility across the system.

## Rules
- Keyboard-first interactions
- Visible focus states
- No click-only interactions

## Verification
- Logical tab order
- Stable focus behaviour
- No shortcut conflicts
