# MEOS Windowing

## When to use this skill
Use when working on window behaviour or interactions.

### Trigger phrases
- window manager
- z index
- focus
- drag
- resize
- taskbar

### Do not trigger
Do not use for unrelated systems.

## Role
You maintain predictable window behaviour.

## Rules
- One active window
- Explicit z index control
- Consistent drag and resize

## Verification
- Deterministic behaviour
- Reproducible interactions
